📐 Indicadores que Devemos Monitorar (KPIs)
1. Latência (RTT)
Tempo de ida e volta do pacote. Mede quão rápido o cliente acessa o serviço.
✓ <50ms · ⚠ <100ms · 🔴 >200ms
2. Jitter
Variação da latência entre pacotes. Afeta streaming, gaming e VoIP.
✓ <10ms · ⚠ <30ms · 🔴 >50ms
3. Perda de Pacotes
Pacotes que não chegaram. Causa retransmissões TCP e lentidão.
✓ 0% · ⚠ >3% · 🔴 >10%
4. TTFB
Tempo até o primeiro byte. Cliente sente a página "demorando".
✓ <500ms · ⚠ <1000ms · 🔴 >2000ms
5. Resolução DNS
Tempo para resolver domínio. DNS lento afeta TODA a navegação.
✓ <20ms · ⚠ <50ms · 🔴 >100ms
6. Throughput
Taxa de download. Queda indica congestionamento no upstream.
✓ >80% · ⚠ 50-80% · 🔴 <50%
7. Status HTTP
200=OK, 3xx=redirect, 403/417=acesso negado, 5xx=erro servidor.
✓ 2xx · ⚠ 3xx · 🔴 4xx/5xx
8. AS Path BGP
Número de hops de AS até o destino. Mais hops = rota mais frágil.
✓ 2-3 hops · ⚠ 4-5 · 🔴 >5
9. Tráfego por AS
Volume por destino. Mostra quais serviços consomem mais banda.
✓ Balanceado · ⚠ 1 AS >50% · 🔴 Saturação
10. Disponibilidade
Percentual de testes bem-sucedidos. Meta de SLA do provedor.
✓ 99.9% · ⚠ 99% · 🔴 <99%
