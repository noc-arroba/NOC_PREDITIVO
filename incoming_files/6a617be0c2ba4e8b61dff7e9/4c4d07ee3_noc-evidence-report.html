Metodologia de Evidência

1

Duas fontes independentes de medição: Monitoramento externo (servidor independente via HTTPS) e interno (roteadores MX204-CENTRO e MX204-STA-ROSA via RR Flow API). Se ambas detectam o mesmo problema, a evidência é irrefutável.

2

Traceroute hop-a-hop de dentro do Arroba: Identifica exatamente em qual hop/AS está o gargalo de latência. Dados coletados via API do RR Flow dos roteadores reais.

3

Thresholds baseados em impacto ao cliente: Latência >200ms = crítico (cliente sente lentidão), Jitter >50ms = crítico (streaming/gaming afetado), Perda >3% = cliente nota, TTFB >1000ms = páginas demoram.

4

Correlação multi-serviço: Quando múltiplos serviços degradam simultaneamente, indica problema de infraestrutura (upstream/roteamento), não de serviço individual.

5

Tendência histórica: Comparação com medições anteriores detecta degradação gradual antes do cliente reclamar.
